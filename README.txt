THE KARIGAR'S — GitHub Pages website

This package has the product-upload section removed. It includes the 59 product catalog and product images.

To publish: upload ALL files in this folder to the root of your existing GitHub repository, replacing index.html and existing same-name files, then commit. Keep index.html at the repository root. GitHub Pages is already enabled on your repository.

Note: This is a static front-end. Product changes need editing the site files; customer orders are sent via WhatsApp according to the number configured in index.html.
